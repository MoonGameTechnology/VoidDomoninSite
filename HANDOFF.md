# Void Dominion — готовый редизайн

Реализован выбранный второй вариант: горизонт планеты, светлый заголовок, две кнопки, адаптивная мобильная версия. Кнопка «Играть в браузере» ведёт на https://moongametechnology.github.io/MoonGame/ . Ссылка обновлена во всех локализациях.

## Запуск

```sh
npm ci
npm run dev
```

## Проверка и сборка

```sh
npm run lint
npm run build
```

Для GitHub Pages сохранён существующий workflow и параметр VITE_BASE.

Архив содержит полный исходный проект без node_modules, .git и временной страницы проверки. Распакуйте в рабочую копию MoonGameTechnology/VoidDomoninSite, просмотрите изменения и отправьте их обычным способом. Автоматическая запись через подключённый GitHub не выполнена: API вернул 403 Resource not accessible by integration при создании ветки. Опубликованный сайт не изменён.

Скриншоты проверки находятся в review/, результаты — в design-qa.md.
